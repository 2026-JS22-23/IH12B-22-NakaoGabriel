# Sao Paulo Tourism

ブラジルのサンパウロを紹介する観光サイトです。サンパウロの有名な観光スポットを、写真と説明付きで紹介しています。

## コンテンツ

- サンパウロを紹介するトップページ
- おすすめ観光スポットの一覧
- MASP、リベルダージ、イビラプエラ公園、市営市場の紹介
- 観光スポットの画像ギャラリー
- ページ内のナビゲーションと地図

## 使用技術

- HTML5
- CSS3
- JavaScript
- jQuery UI

## 実行方法

1. プロジェクトをダウンロード、またはクローンします。
2. `index.html` をブラウザで開きます。

Visual Studio Codeの **Live Server** 拡張機能を使うと、開発中のサイトを簡単に確認できます。

## プロジェクト構成

```text
index.html       メインページ
css/style.css    サイトのスタイル
images/          プロジェクトで使用する画像
```
